# Bootstrap zips go here

Place architecture-specific Termux bootstrap files:

- bootstrap-aarch64.zip
- bootstrap-arm.zip
- bootstrap-x86_64.zip (optional)

Download from:
https://github.com/termux/termux-packages/releases

After placing the zip, the BootstrapManager will extract it on first run
and recreate all symlinks from SYMLINKS.txt (official Termux method).
